Définition

Les symboles de l'algorigramme

  • Ovale : début ou fin« Début ». Pas de « Fin » si le système boucle.
  • Parallélogramme : entrée ou sortieLire un capteur, afficher une valeur.
  • Rectangle : instructionAllumer, arrêter, attendre, calculer, affecter.
  • Losange : conditionUne question. Sortie Oui en bas, sortie Non à droite.
  • Doubles barres : sous-programmeUn bloc détaillé dans un autre algorigramme.

Affectation : la flèche « ← » range une valeur dans une variable, par exemple compteur ← compteur + 1.

Méthode

Compléter un algorigramme à partir d'un texte

  1. Surligne les capteurs (entrées), les actionneurs (sorties) et les mots de condition.
  2. Chaque capteur donne une acquisition, placée juste avant le test qui l'utilise.
  3. Chaque « si », « lorsque », « au-delà de » donne un losange, écrit comme une question.
  4. Vérifie que la sortie Oui mène à l'action demandée et la sortie Non à l'autre cas.
  5. Relis avec une valeur test (« il fait 30 °C ») en suivant les flèches.

À retenir

La structure d'un programme Arduino

const int pinLed = 13;      // 1. déclarations

void setup() {              // 2. une seule fois
  pinMode(pinLed, OUTPUT);
}

void loop() {               // 3. en boucle, sans fin
  digitalWrite(pinLed, HIGH);
  delay(500);
  digitalWrite(pinLed, LOW);
  delay(500);
}
  • « Début » et ce qui est fait « au démarrage » : dans setup().
  • La boucle de l'algorigramme : dans loop(). Il n'y a pas de « Fin ».
  • Chaque instruction se termine par ; et chaque bloc est entre { }.
Définition

Variables et types

Une variable est une case mémoire qui porte un nom et contient une valeur d'un certain type.

TypeContientExemple
const intun entier qui ne change pas (broche)const int pinPompe = 7;
intun entierint n = analogRead(A0);
floatun nombre à virgulefloat temperature = 24.5;
boolvrai ou fauxbool presence = true;

Noms en camelCase sans accent (pinPompe, temperature). En C, on écrit un point à la place de la virgule : 24.5.

À retenir

Entrées, sorties et temps

pinMode(7, OUTPUT);dans setup() : D7 est une sortie (actionneur). INPUT pour un capteur.
digitalWrite(7, HIGH);met la sortie à 5 V (HIGH) ou à 0 V (LOW).
digitalRead(2)lit un capteur tout ou rien : renvoie HIGH ou LOW.
analogRead(A0)lit une tension de 0 à 5 V : renvoie N, de 0 à 1023.
delay(1000);attend, en millisecondes : 1000 ms = 1 s.
Serial.begin(9600);ouvre la liaison série (dans setup()) ; Serial.println(x); envoie x.
Conseil pour l'épreuve

HIGH ou LOW ? Regarde le câblage

CâblageÀ écrire
Charge (LED, relais) entre la broche et GNDHIGH pour l'activer
Charge entre le +5 V et la brocheLOW pour l'activer
Bouton avec résistance pull-up (vers +5 V)appuyé : LOW
Bouton avec résistance pull-down (vers GND)appuyé : HIGH
Relais « actif à l'état haut »HIGH le colle
Relais « actif à l'état bas »LOW le colle

Justifie toujours ton choix par le câblage : c'est ce que le correcteur attend.

Exemple

De la valeur N à la grandeur mesurée

Arduino Uno : convertisseur 10 bits, plage de 0 à 5 V.

Quantumq = 5 V / 210 = 5 / 1024 ≈ 4,88 mV
Valeur numériqueN = partie entière de Ue / q
TensionUe ≈ N × q
Grandeurgrandeur = Ue / sensibilité

LM35 (10 mV/°C) à 24,5 °C : Ue = 0,245 V, donc N = partie entière de 0,245 / 0,004 883 = 50. Dans le programme : temperature = n * 5.0 / 1024 * 100;

Certains sujets divisent par 1023 au lieu de 1024 (fonction map()) : suis toujours la formule donnée par le sujet.

Attention, piège

Les pièges classiques

  • = range une valeur, == compare : if (presence == HIGH).
  • && = ET (les deux conditions), || = OU (une seule suffit).
  • delay() compte en millisecondes : 30 s s'écrit delay(30000).
  • Lis le capteur dans la boucle, sinon sa valeur ne change plus.
  • Relais actif à l'état bas : écris HIGH au démarrage pour que tout reste éteint.
  • HIGH, LOW, OUTPUT s'écrivent en majuscules ; chaque instruction finit par ;.
